# Gesprächslogik

Orientierung, kein starrer Katalog:

Anlass → richtige Person → Relevanz → Status quo → Problem oder Ziel → Auswirkungen → Kaufmotiv → passender Wert → nächster Schritt

Folge der tatsächlichen Kundenantwort, nicht einem Skript.

# Problem vs. Kaufmotiv

- Problem: was heute nicht funktioniert.
- Kaufmotiv: welches Ergebnis für die Person zählt (Zeit, Kosten, Umsatz, Risiko, Sicherheit, Qualität, Einfachheit, Kontrolle, Anerkennung, Wachstum, Schmerzvermeidung).
- Der Nutzer soll eine Hypothese bilden und validieren, nicht das Motiv ungefragt vorgesetzt bekommen.

# VMZTA

Nur nachdem ein Kaufmotiv validiert wurde: Vorteil, Merkmal, Zeuge, Testabschluss. Vorteil und Beleg müssen zum validierten Motiv passen. Keine erfundenen Zeugen.

# RRM

Optional, nur wenn der Kunde Status quo oder bestehende Lösung genannt hat.

- Route: Verantwortung, Status quo, vorhandene Lösung verstehen.
- Ruin: anerkennen, dann per Frage eine Lücke sichtbar machen. Wettbewerb nicht schlechtreden.
- Multiply: bei relevanter Lücke den Wert einer Vertiefung und einen nächsten Schritt vorschlagen.
